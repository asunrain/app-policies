简介

2048 plus（以下简称"本应用"）是一款 Android 平台的数字合并益智游戏，您可以通过合并数字方块不断挑战 2048 及更高分数。本游戏支持离线游玩，无需注册或登录任何账号。

我们高度重视您的隐私。本隐私政策说明了您使用本应用时会处理哪些信息、这些信息如何被使用与保护，以及您可以做出的选择。安装并使用本应用，即表示您知悉并认可本政策所述的做法。

我们收集哪些信息

我们不会收集、上传或存储任何可识别个人身份的信息至我们自己的服务器。具体而言：

  • 无需账号：本应用不要求注册或登录，不收集用户名、邮箱、密码或电话号码。
  • 无自有行为分析：本应用不使用自有的统计 SDK 对您进行画像分析。
  • 游戏数据仅保存在您的设备上：游戏进度、当前分数与最高分、棋盘尺寸、皮肤与自定义方块文字/颜色、音效、夜间模式、重力模式，以及（如您使用）自定义背景图片和备份文件，都仅保存在本应用的本地存储中。

但本应用会展示广告，广告 SDK 会自动处理部分数据，请阅读下文第 3 节。

广告与第三方服务

本应用为免费应用，通过 Google AdMob（Google Mobile Ads SDK）投放的广告获得支持。广告以屏幕底部横幅形式展示，并偶尔以全屏（插屏）广告形式展示。

为投放广告，Google Mobile Ads SDK 可能会自动收集并共享以下信息：

  • 您设备的广告标识符（Android 广告 ID）和应用集 ID（App Set ID）；
  • 您的 IP 地址（可据此推断出城市级别的粗略位置）；
  • 设备类型、操作系统版本、语言等技术信息；
  • 向您展示的广告及您与广告互动的相关信息。

上述信息用于广告投放与营销、统计分析和防范欺诈，并可能与 Google 的广告合作伙伴共享，均通过加密连接传输。

您可以随时在设备上控制广告标识符与个性化广告：

  • Android：设置 → 隐私 → 广告（或 Google → 广告）——删除或重置广告 ID，或关闭广告个性化。
  • 在法律要求的情况下（欧洲经济区、英国、瑞士），我们会在请求任何广告之前，通过经 Google 认证的同意管理平台展示同意表单，您可以选择接受或拒绝个性化广告。

关于 Google 如何处理这些数据，请参阅：

  • Google 隐私权政策：https://policies.google.com/privacy
  • Google 如何使用来自使用我们服务的网站或应用的信息：https://policies.google.com/technologies/partner-sites

除 Google AdMob 外，本应用不集成任何第三方分析、广告或追踪服务。

我们如何使用信息

由于我们不收集个人信息，因此不存在对您个人信息的使用。广告 SDK 处理的有限信息仅用于展示广告、衡量广告效果和防范欺诈，详见第 3 节。

我们不会出售您的个人信息，也不会将您的数据用于与应用运行及其广告无关的任何目的。

应用权限说明

本应用仅申请实现其功能所必需的权限：

  • android.permission.INTERNET——用于请求广告。
  • android.permission.ACCESS_NETWORK_STATE——用于在请求广告前检查网络连接状态。
  • com.google.android.gms.permission.AD_ID——允许 Google Mobile Ads SDK 访问广告标识符（Android 13 及更高版本的强制要求）。

Google Mobile Ads SDK 还会声明少数由 Google Play 服务使用的权限（如 WAKE_LOCK、FOREGROUND_SERVICE），用于保证广告投放的稳定性。

本应用不会申请访问您的联系人、精确位置、相机、麦克风、照片、文件或外部存储。如果您选择自定义背景图片，该图片通过系统文件选择器选取并复制到本应用的私有目录中，本应用不会获得对您文件或相册的广泛访问权限。

数据存储与安全

所有游戏数据均保存在您设备的本地存储中（本应用的私有 SharedPreferences 与应用专属文件目录）。我们不会在任何服务器上保留副本。

本地保存的数据包括：游戏进度与分数、皮肤与自定义设置、自定义背景图片（如您设置过）以及通过应用内备份功能生成的备份文件。

卸载本应用会删除以上全部数据；您也可以随时通过 Android 设置 → 应用 → 2048 plus → 存储 → 清除存储 将其清除。本应用的正常运行无需任何存储权限。

我们采取合理的技术措施保护我们控制的数据。请注意，任何传输或存储方式都无法保证百分之百安全。

您的权利：您有权访问、更正、删除和限制处理您的个人数据，有权要求数据可携带，有权反对处理，并有权随时撤回您的同意。撤回同意不影响撤回之前已进行的处理的合法性。

您在加利福尼亚州的隐私权利

如果您是加利福尼亚州居民，CCPA/CPRA 赋予您关于个人信息的特定权利。

  • 在过去 12 个月内，广告 SDK 可能已将广告 ID 等标识符与广告合作伙伴"共享"（CPRA 定义），用于跨情境行为广告，详见第 3 节。我们不会为获取金钱利益而出售个人信息。
  • 您有权选择退出将您的个人信息用于定向广告的共享。最简单的方式是在设备设置中关闭广告个性化或删除广告 ID（见第 3 节），或在出现同意表单时选择拒绝。
  • 您还有权知晓、删除和更正您的个人信息，并且不会因行使这些权利而受到歧视。

如需提出请求，请通过 android.sun.rain@gmail.com 与我们联系。我们不会在明知的情况下出售或共享 16 岁以下消费者的个人信息。

儿童隐私

本应用不面向 13 岁以下儿童（当地法律要求 16 岁的地区从其规定），我们不会在明知的情况下收集儿童的个人信息。本游戏不包含用户生成内容、聊天、私信或社交功能。

如果您认为有儿童向我们提供了个人信息，请与我们联系，我们将尽快删除。家长或监护人也可以按照第 3 节所述，在设备上关闭广告个性化。

数据保留期限

我们不会在服务器上保留个人数据。保存在您设备本地的数据会一直保留，直到您清除本应用的存储或卸载本应用。Google Mobile Ads SDK 处理的数据按照 Google 自身的保留政策进行保留。

跨境数据传输

广告数据可能会被 Google 及其合作伙伴传输至您所在国家/地区以外的国家（包括美国）进行处理。在需要时，此类传输将依据适当的安全保障措施进行，例如欧盟委员会的标准合同条款（SCC）以及欧盟-美国数据隐私框架（EU-US DPF）。

政策变更

我们可能会不时更新本隐私政策。更新后的版本将在本页面发布，并更新顶部的"最后更新日期"。如发生重大变更，我们会在应用内或商店页面中予以提示。

在政策更新后继续使用本应用，即视为您接受修订后的政策。
