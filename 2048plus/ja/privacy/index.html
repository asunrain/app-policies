はじめに

2048 plus（以下「本アプリ」）は、数字のタイルを合体させて 2048 以上のタイルを目指す Android 向けの数字パズルゲームです。オフラインで遊ぶことができ、アカウント登録やログインは不要です。

私たちはお客様のプライバシーを重視しています。本プライバシーポリシーは、本アプリの利用時にどのような情報が処理されるか、その情報がどのように利用・保護されるか、そしてお客様がどのような選択を行えるかを説明するものです。本アプリをインストールして利用することにより、お客様は本ポリシーに記載された内容を認識し同意したものとみなされます。

収集する情報

私たちは、個人を特定できる情報を当社のサーバーに収集・送信・保存することはありません。具体的には次のとおりです。

  • アカウント不要：登録やログインは必要なく、ユーザー名、メールアドレス、パスワード、電話番号などは収集しません。
  • 独自の行動分析なし：独自の分析 SDK を用いたプロファイリングは行いません。
  • ゲームデータは端末内のみ：ゲームの進行状況、現在のスコアとハイスコア、盤面サイズ、スキンおよびタイルの文字・色のカスタマイズ、サウンド、ナイトモード、重力モード、さらに（使用した場合）カスタム背景画像とバックアップファイルは、本アプリのローカルストレージにのみ保存されます。

ただし、本アプリは広告を表示するため、広告 SDK が一部のデータを自動的に処理します。以下の第 3 項をご確認ください。

広告および第三者サービス

本アプリは無料で提供されており、Google AdMob（Google Mobile Ads SDK）による広告によって運営されています。広告は画面下部のバナーとして、また場合によっては全画面（インタースティシャル）広告として表示されます。

広告を配信するため、Google Mobile Ads SDK は以下の情報を自動的に収集し共有する場合があります。

  • 端末の広告識別子（Android 広告 ID）およびアプリセット ID
  • IP アドレス（これにより都市レベルのおおよその位置が推定される場合があります）
  • 端末の種類、OS のバージョン、言語などの技術情報
  • 表示された広告およびお客様の広告との操作に関する情報

これらの情報は、広告の配信とマーケティング、分析、不正防止のために使用され、Google の広告パートナーと共有される場合があります。送信はすべて暗号化された接続を経由します。

広告識別子およびパーソナライズ広告は、いつでも端末側で管理できます。

  • Android：設定 → プライバシー → 広告（または Google → 広告）——広告 ID の削除・リセット、または広告のパーソナライズのオプトアウトができます。
  • 法令により求められる地域（欧州経済領域、英国、スイス）では、広告をリクエストする前に、Google 認定の同意管理プラットフォームによる同意フォームを表示します。パーソナライズ広告を承諾するか拒否するかを選択できます。

Google によるこれらのデータの取り扱いについては、以下をご参照ください。

  • Google プライバシー ポリシー：https://policies.google.com/privacy
  • Google サービスを利用するサイトやアプリから Google が情報を取得する方法：https://policies.google.com/technologies/partner-sites

Google AdMob を除き、本アプリは第三者の分析・広告・トラッキングサービスを一切組み込んでいません。

情報の利用目的

私たちは個人情報を収集していないため、お客様の個人情報を利用することはありません。広告 SDK が処理する限られた情報は、第 3 項に記載のとおり、広告の表示、成果の測定、不正防止のためにのみ使用されます。

私たちはお客様の個人情報を販売しません。また、本アプリの運営およびその広告と無関係な目的でデータを利用することもありません。

アプリの権限

本アプリは、その機能に必要な権限のみを要求します。

  • android.permission.INTERNET——広告をリクエストするために必要です。
  • android.permission.ACCESS_NETWORK_STATE——広告をリクエストする前にネットワーク接続の状態を確認するために使用します。
  • com.google.android.gms.permission.AD_ID——Google Mobile Ads SDK が広告識別子にアクセスすることを許可します（Android 13 以降で必須）。

Google Mobile Ads SDK は、広告配信の安定性のために、Google Play 開発者サービスが使用する少数の権限（WAKE_LOCK、FOREGROUND_SERVICE など）も宣言します。

本アプリは、連絡先、正確な位置情報、カメラ、マイク、写真、ファイル、外部ストレージへのアクセスを要求しません。カスタム背景画像を選択した場合、その画像はシステムのファイル選択画面を通じて選択され、本アプリのプライベート領域にコピーされます。本アプリがお客様のファイルや写真ライブラリへの広範なアクセス権を取得することはありません。

データの保存と安全管理

すべてのゲームデータは、お客様の端末内のローカルストレージ（本アプリ専用の SharedPreferences およびアプリ専用ファイルディレクトリ）に保存されます。当社のサーバーに複製を保管することはありません。

ローカルに保存されるデータには、ゲームの進行状況とスコア、スキンおよびカスタマイズ設定、カスタム背景画像（設定した場合）、アプリ内バックアップ機能で作成したバックアップファイルが含まれます。

本アプリをアンインストールすると、これらのデータはすべて削除されます。また、Android の設定 → アプリ → 2048 plus → ストレージ → ストレージを消去 からいつでも消去できます。本アプリの動作にストレージ権限は必要ありません。

私たちは、当社が管理するデータを保護するために合理的な技術的措置を講じています。ただし、いかなる送信・保存方法も完全に安全とは限らない点にご留意ください。

GDPR / UK GDPR に基づくお客様の権利

お客様が欧州経済領域、英国、またはスイスにお住まいの場合、以下が適用されます。

処理の法的根拠（GDPR 第 6 条）：

  • 同意——パーソナライズ広告および広告識別子の使用のため。広告をリクエストする前に、Google 認定の同意管理プラットフォームによる同意フォームを表示します。承諾または拒否を選択できます。
  • 正当な利益——非パーソナライズ広告の配信、アプリの正常な動作の維持、不正および濫用の防止のため。

お客様の権利：お客様は、個人データへのアクセス、訂正、削除、処理の制限を求める権利、データポータビリティの権利、異議を述べる権利、およびいつでも同意を撤回する権利を有します。撤回は、撤回前に行われた処理の適法性には影響しません。

これらの権利を行使するには、android.sun.rain@gmail.com までご連絡ください。また、お住まいのデータ保護監督機関に苦情を申し立てる権利もあります。

本アプリ自体は個人データを収集しないため、広告データに関するご請求は、当該サービスの提供者である Google に直接お問い合わせいただくのが適切です。私たちは可能な範囲でサポートいたします。

カリフォルニア州のプライバシー権

お客様がカリフォルニア州の居住者である場合、CCPA/CPRA により個人情報に関する特定の権利が認められます。

  • 過去 12 か月間において、広告 SDK は広告 ID などの識別子を、第 3 項に記載のとおりクロスコンテキスト行動ターゲティング広告のために広告パートナーと「共有」（CPRA の定義）した可能性があります。私たちは金銭的対価を得て個人情報を販売することはありません。
  • お客様は、ターゲティング広告のための個人情報の共有をオプトアウトする権利を有します。最も簡単な方法は、端末の設定で広告のパーソナライズを無効にするか広告 ID を削除すること（第 3 項）、または同意フォームが表示された際に拒否を選択することです。
  • お客様はまた、個人情報の開示請求、削除、訂正を求める権利を有し、これらの権利を行使したことを理由に差別的な扱いを受けません。

ご請求は android.sun.rain@gmail.com までご連絡ください。16 歳未満の消費者の個人情報を、故意に販売または共有することはありません。

児童のプライバシー

本アプリは 13 歳未満の児童（現地法が 16 歳を求める地域ではその年齢未満の児童）を対象としておらず、児童の個人情報を故意に収集することはありません。本ゲームにはユーザー生成コンテンツ、チャット、メッセージ、ソーシャル機能はありません。

児童が個人情報を提供したと思われる場合は、ご連絡いただければ速やかに削除します。保護者の方は、第 3 項に従って端末側で広告のパーソナライズを無効にすることもできます。

データの保持期間

私たちはサーバー上に個人データを保持しません。端末のローカルに保存されたデータは、本アプリのストレージを消去するかアンインストールするまで保持されます。Google Mobile Ads SDK が処理するデータは、Google 自身の保持ポリシーに従って保持されます。

国際的なデータ移転

広告データは、Google およびそのパートナーにより、お客様の居住国以外の国（米国を含む）に移転され、処理される場合があります。必要な場合、こうした移転は、欧州委員会の標準契約条項（SCC）や EU-米国データプライバシーフレームワーク（EU-US DPF）など、適切な保護措置に基づいて行われます。

本ポリシーの変更

私たちは本プライバシーポリシーを随時更新することがあります。更新後の版は本ページに掲載し、「最終更新日」を更新します。重要な変更がある場合は、アプリ内またはストアの掲載情報でお知らせします。

更新後も本アプリの利用を継続された場合、改訂後のポリシーに同意したものとみなされます。
