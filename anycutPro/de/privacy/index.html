Einleitung

AnyCut (im Folgenden „diese App“) ist ein Android-Verknüpfungserstellungswerkzeug, das Benutzern ermöglicht, Startbildschirm-Verknüpfungen für Telefonanrufe, SMS, Websites, Dateien, Systemeinstellungen und mehr zu erstellen.

Wir nehmen Ihre Privatsphäre ernst. Diese Datenschutzerklärung erläutert unsere Praktiken in Bezug auf die Erhebung, Verwendung und den Schutz von Informationen. Durch die Nutzung dieser App stimmen Sie den in dieser Datenschutzerklärung beschriebenen Bedingungen zu.

Welche Informationen wir erheben

Diese App nicht erhebt, hochlädt oder speichert personenbezogene Daten. Im Einzelnen:

  • Diese App erfordert keine Registrierung oder Anmeldung und erhebt keine Benutzernamen, E-Mail-Adressen, Passwörter oder sonstige Kontoinformationen.
  • Diese App erhebt keine Gerätekennungen (wie IMEI, Android-ID), Standortinformationen oder sonstige Gerätedaten.
  • Diese App verwendet keine Web-Analyse-Tools (wie Google Analytics), um das Benutzerverhalten zu verfolgen.
  • Diese App enthält keine Werbe-SDKs.

Alle von Benutzern erstellten Verknüpfungsdaten (wie Auswahl von Kontakten, benutzerdefinierte Symbole usw.) werden auf dem lokalen Gerät gespeichert und niemals an einen Server gesendet.

Wie wir Informationen verwenden

Da diese App keine personenbezogenen Daten erhebt, gibt es keine weitere Verwendung personenbezogener Daten. Diese App verarbeitet lediglich die folgenden Daten lokal:

  • Kontaktinformationen: Wenn Sie eine Telefon- oder SMS-Verknüpfung erstellen, liest diese App den von Ihnen ausgewählten Kontaktnamen und die Telefonnummer, um eine lokale Verknüpfung zu erstellen. Diese Informationen werden nur in der Verknüpfung selbst gespeichert und niemals hochgeladen oder geteilt.
  • Liste installierter Apps: Wenn Sie eine App-Verknüpfung erstellen, liest diese App die Liste der auf Ihrem Gerät installierten Apps zur Auswahl und lädt diese Liste nicht hoch.
  • Datei-/Ordnerpfade: Wenn Sie eine Datei- oder Ordnerverknüpfung erstellen, speichert diese App nur die von Ihnen ausgewählte Datei-URI und liest oder lädt keine Dateiinhalte hoch.
  • Web-Symbole: Wenn Sie eine Website-Verknüpfung erstellen, ruft diese App das Website-Symbol über die Google Favicon API ab. Diese Anfrage enthält nur die Website-Domain und keine personenbezogenen Daten.

App-Berechtigungen

Diese App fordert die folgenden Berechtigungen an, jeweils mit einem klaren Zweck:

  • READ_CONTACTS: Wird verwendet, um Kontakte beim Erstellen von Telefon-/SMS-Verknüpfungen auszuwählen. Wird nur während benutzerinitiierter Aktionen gelesen, niemals im Hintergrund oder hochgeladen.
  • READ_EXTERNAL_STORAGE: Wird verwendet, um Dateien, Ordner und benutzerdefinierte Symbole auszuwählen. Wird nur zugegriffen, wenn der Benutzer diese aktiv auswählt.
  • QUERY_ALL_PACKAGES: Wird verwendet, um installierte Apps beim Erstellen von App-Verknüpfungen aufzulisten.
  • INSTALL_SHORTCUT: Wird verwendet, um Verknüpfungen auf dem Startbildschirm zu erstellen.

Datenspeicherung und Sicherheit

Alle Daten in dieser App werden im lokalen Speicher des Geräts des Benutzers gespeichert, einschließlich:

  • Verknüpfungskonfigurationsinformationen werden in den SharedPreferences der App gespeichert.
  • Benutzerdefinierte Symbole werden lokal auf dem Gerät gespeichert.

Diese App synchronisiert keine Daten mit der Cloud oder Remote-Servern. Beim Deinstallieren dieser App werden automatisch alle lokalen Daten gelöscht.

Benutzer können alle zugehörigen Daten jederzeit durch Deinstallieren dieser App löschen.

Drittanbieter-Dienste

Beim Erstellen von Website-Verknüpfungen ruft diese App Website-Symbole über den folgenden Dienst ab:

  • Google Favicon API (https://www.google.com/s2/favicons): Es wird nur die Website-Domain gesendet, um das entsprechende Symbol abzurufen. Es sind keine Benutzeridentitätsinformationen enthalten.

Abgesehen vom oben genannten Dienst integriert diese App keine Drittanbieter-Analyse-, Werbe- oder Verfolgungsdienste.
