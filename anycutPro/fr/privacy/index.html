Introduction

AnyCut (ci-après « cette application ») est un outil de création de raccourcis Android qui permet aux utilisateurs de créer des raccourcis sur l'écran d'accueil pour les appels téléphoniques, les SMS, les sites web, les fichiers, les paramètres système, et plus encore.

Nous prenons votre confidentialité au sérieux. Cette politique de confidentialité explique nos pratiques en matière de collecte, d'utilisation et de protection des informations. En utilisant cette application, vous acceptez les termes décrits dans cette politique de confidentialité.

Informations que nous collectons

Cette application ne collecte, ne télécharge ni ne stocke aucune information nominative. Plus précisément :

  • Cette application ne nécessite ni inscription ni connexion et ne collecte aucun nom d'utilisateur, e-mail, mot de passe ou autre information de compte.
  • Cette application ne collecte aucun identifiant d'appareil (tel que l'IMEI, l'Android ID), aucune information de localisation ou autre donnée d'appareil.
  • Cette application n'utilise aucun outil d'analyse web (tel que Google Analytics) pour suivre le comportement des utilisateurs.
  • Cette application ne contient aucun SDK publicitaire.

Toutes les données de raccourci créées par les utilisateurs (telles que les enregistrements de sélection de contacts, les icônes personnalisées, etc.) sont stockées sur l'appareil local et ne sont jamais envoyées à un serveur.

Comment nous utilisons les informations

Étant donné que cette application ne collecte aucune information personnelle, il n'y a pas d'autre utilisation des informations personnelles. Cette application traite uniquement les données suivantes localement :

  • Informations de contact : Lorsque vous créez un raccourci d'appel ou de SMS, cette application lit le nom du contact et le numéro de téléphone que vous sélectionnez afin de générer un raccourci local. Ces informations sont uniquement enregistrées dans le raccourci lui-même et ne sont jamais téléchargées ni partagées.
  • Liste des applications installées : Lorsque vous créez un raccourci d'application, cette application lit la liste des applications installées sur votre appareil pour votre sélection et ne télécharge pas cette liste.
  • Chemins de fichier/dossier : Lorsque vous créez un raccourci de fichier ou de dossier, cette application enregistre uniquement l'URI du fichier que vous avez sélectionné et ne lit ni ne télécharge le contenu du fichier.
  • Icônes web : Lorsque vous créez un raccourci de site web, cette application récupère l'icône du site via l'API Google Favicon. Cette requête ne contient que le domaine du site et aucune information personnelle.

Autorisations de l'application

Cette application demande les autorisations suivantes, chacune ayant un objectif clair :

  • READ_CONTACTS : Utilisé pour sélectionner des contacts lors de la création de raccourcis d'appel/SMS. Uniquement lu lors d'actions initiées par l'utilisateur, jamais en arrière-plan ni téléchargé.
  • READ_EXTERNAL_STORAGE : Utilisé pour sélectionner des fichiers, des dossiers et des icônes personnalisées. Uniquement accédé lorsque l'utilisateur les sélectionne activement.
  • QUERY_ALL_PACKAGES : Utilisé pour lister les applications installées lors de la création de raccourcis d'application.
  • INSTALL_SHORTCUT : Utilisé pour créer des raccourcis sur l'écran d'accueil.

Stockage et sécurité des données

Toutes les données de cette application sont stockées dans le stockage local de l'appareil de l'utilisateur, notamment :

  • Les informations de configuration des raccourcis sont stockées dans les SharedPreferences de l'application.
  • Les icônes personnalisées sont stockées localement sur l'appareil.

Cette application ne synchronise aucune donnée vers le cloud ou des serveurs distants. La désinstallation de cette application supprimera automatiquement toutes les données locales.

Les utilisateurs peuvent supprimer toutes les données associées à tout moment en désinstallant cette application.

Services tiers

Lors de la création de raccourcis de sites web, cette application récupère les icônes de sites via le service suivant :

  • API Google Favicon (https://www.google.com/s2/favicons) : Seul le domaine du site est envoyé pour récupérer l'icône correspondante. Aucune information d'identité de l'utilisateur n'est incluse.

À part le service ci-dessus, cette application n'intègre aucun service tiers d'analyse, de publicité ou de suivi.

Conformité au RGPD

Conformément au Règlement général sur la protection des données (RGPD) de l'Union européenne, nous déclarons par la présente :

  • Contrôleur de données : AnyCut agit en tant que contrôleur de données. Étant donné que cette application ne collecte aucune donnée personnelle, aucune demande relative aux droits des personnes concernées n'est nécessaire.
  • Base légale : Cette application ne traite pas de données personnelles, aucune base légale au titre de l'article 6 du RGPD n'est donc requise.
  • Droits des personnes concernées : Bien que cette application ne collecte pas de données personnelles, vous conservez tous les droits prévus par le RGPD, notamment le droit d'accès, de rectification, d'effacement, de limitation du traitement, de portabilité des données et d'opposition.
  • Notification de violation de données : Étant donné qu'aucune donnée personnelle n'est collectée ni stockée, des violations de données affectant les données personnelles des utilisateurs ne peuvent pas survenir.
  • Délégué à la protection des données (DPO) : Étant donné que cette application ne traite pas de données personnelles, aucun délégué à la protection des données (DPO) n'a été désigné. Pour toute question relative à la confidentialité, veuillez nous contacter à android.sun.rain@gmail.com.

Si vous avez des préoccupations concernant la conformité au RGPD, vous avez le droit de déposer une plainte auprès de votre autorité locale de protection des données ou de l'autorité de contrôle de l'État membre de l'UE dans lequel vous résidez.

Confidentialité des enfants

Cette application n'est pas destinée aux enfants de moins de 13 ans, et nous ne collectons sciemment aucune information personnelle auprès des enfants. Étant donné que cette application ne collecte aucune information personnelle, il n'y a aucune menace pour la confidentialité des enfants. Si vous découvrez qu'un enfant nous a fourni des informations, veuillez nous contacter et nous y remédierons rapidement.

Modifications de la politique

Nous pouvons mettre à jour cette politique de confidentialité de temps à autre. Les politiques mises à jour seront publiées sur cette page avec une date de « Dernière mise à jour » actualisée. Nous recommandons aux utilisateurs de consulter cette page régulièrement pour obtenir la dernière politique de confidentialité.

En cas de modifications importantes de la politique, nous informerons les utilisateurs par le biais de notifications visibles dans l'application.
