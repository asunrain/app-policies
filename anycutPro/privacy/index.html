Introduction

AnyCut (hereinafter "this app") is an Android shortcut creation tool that allows users to create home screen shortcuts for phone calls, SMS, websites, files, system settings, and more.

We take your privacy seriously. This privacy policy explains our practices regarding information collection, use, and protection. By using this app, you agree to the terms described in this privacy policy.

Information We Collect

This app does not collect, upload, or store any personally identifiable information. Specifically:

  • This app does not require registration or login and does not collect usernames, emails, passwords, or other account information.
  • This app does not collect device identifiers (such as IMEI, Android ID), location information, or other device data.
  • This app does not use any web analytics tools (such as Google Analytics) to track user behavior.
  • This app does not contain any advertising SDKs.

All shortcut data created by users (such as contact selection records, custom icons, etc.) is stored on the local device and is never sent to any server.

How We Use Information

Since this app does not collect any personal information, there is no further use of personal information. This app only processes the following data locally:

  • Contact information: When you create a phone or SMS shortcut, this app reads the contact name and phone number you select to generate a local shortcut. This information is only saved in the shortcut itself and is never uploaded or shared.
  • Installed app list: When you create an app shortcut, this app reads the list of installed apps on your device for your selection and does not upload this list.
  • File/folder paths: When you create a file or folder shortcut, this app only saves the file URI you selected and does not read or upload file contents.
  • Web icons: When you create a website shortcut, this app fetches the website icon via the Google Favicon API. This request only contains the website domain and no personal information.

App Permissions

This app requests the following permissions, each with a clear purpose:

  • READ_CONTACTS: Used to select contacts when creating phone/SMS shortcuts. Only read during user-initiated actions, never in the background or uploaded.
  • READ_EXTERNAL_STORAGE: Used to select files, folders, and custom icons. Only accessed when the user actively selects them.
  • QUERY_ALL_PACKAGES: Used to list installed apps when creating app shortcuts.
  • INSTALL_SHORTCUT: Used to create shortcuts on the home screen.

Data Storage and Security

All data in this app is stored in the local storage of the user's device, including:

  • Shortcut configuration information is stored in the app's SharedPreferences.
  • Custom icons are stored on the device locally.

This app does not sync any data to the cloud or remote servers. Uninstalling this app will automatically delete all local data.

Users can delete all associated data at any time by uninstalling this app.

Third-Party Services

When creating website shortcuts, this app fetches website icons through the following service:

  • Google Favicon API (https://www.google.com/s2/favicons): Only the website domain is sent to fetch the corresponding icon. No user identity information is included.

Apart from the above service, this app does not integrate any third-party analytics, advertising, or tracking services.

GDPR Compliance

In compliance with the General Data Protection Regulation (GDPR) of the European Union, we hereby declare:

  • Data Controller: AnyCut acts as the data controller. Since this app does not collect any personal data, no data subject rights requests are necessary.
  • Legal Basis: This app does not process personal data, so no legal basis under Article 6 of the GDPR is required.
  • Data Subject Rights: Although this app does not collect personal data, you retain all rights under the GDPR, including the right to access, rectify, erase, restrict processing, data portability, and object.
  • Data Breach Notification: Since no personal data is collected or stored, data breaches affecting user personal data cannot occur.
  • Data Protection Officer: Given that this app does not process personal data, a Data Protection Officer (DPO) has not been appointed. For any privacy-related inquiries, please contact us at android.sun.rain@gmail.com.

If you have any concerns regarding GDPR compliance, you have the right to lodge a complaint with your local Data Protection Authority or the supervisory authority in the EU member state where you reside.

Children's Privacy

This app is not directed at children under 13, and we do not knowingly collect personal information from children. Since this app does not collect any personal information, there is no threat to children's privacy. If you discover that a child has provided us with information, please contact us and we will address it promptly.
