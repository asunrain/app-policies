Introducción

AnyCut (en adelante, «esta aplicación») es una herramienta de creación de accesos directos para Android que permite a los usuarios crear accesos directos en la pantalla de inicio para llamadas telefónicas, SMS, sitios web, archivos, ajustes del sistema y más.

Nos tomamos su privacidad en serio. Esta política de privacidad explica nuestras prácticas en relación con la recopilación, el uso y la protección de la información. Al utilizar esta aplicación, usted acepta los términos descritos en esta política de privacidad.

Información que recopilamos

Esta aplicación no recopila, no carga ni almacena ninguna información de identificación personal. En concreto:

  • Esta aplicación no requiere registro ni inicio de sesión y no recopila nombres de usuario, correos electrónicos, contraseñas ni otra información de cuenta.
  • Esta aplicación no recopila identificadores de dispositivo (como IMEI, Android ID), información de ubicación ni otros datos del dispositivo.
  • Esta aplicación no utiliza ninguna herramienta de análisis web (como Google Analytics) para rastrear el comportamiento del usuario.
  • Esta aplicación no contiene ningún SDK de publicidad.

Todos los datos de accesos directos creados por los usuarios (como registros de selección de contactos, iconos personalizados, etc.) se almacenan en el dispositivo local y nunca se envían a ningún servidor.

Cómo utilizamos la información

Dado que esta aplicación no recopila ninguna información personal, no existe ningún uso posterior de la información personal. Esta aplicación solo procesa los siguientes datos localmente:

  • Información de contactos: Cuando usted crea un acceso directo de llamada o SMS, esta aplicación lee el nombre del contacto y el número de teléfono que selecciona para generar un acceso directo local. Esta información solo se guarda en el propio acceso directo y nunca se carga ni se comparte.
  • Lista de aplicaciones instaladas: Cuando usted crea un acceso directo de aplicación, esta aplicación lee la lista de aplicaciones instaladas en su dispositivo para su selección y no carga dicha lista.
  • Rutas de archivos/carpetas: Cuando usted crea un acceso directo de archivo o carpeta, esta aplicación solo guarda el URI del archivo que usted seleccionó y no lee ni carga el contenido de los archivos.
  • Iconos web: Cuando usted crea un acceso directo de sitio web, esta aplicación obtiene el icono del sitio web a través de la API de Google Favicon. Esta solicitud solo contiene el dominio del sitio web y ninguna información personal.

Permisos de la aplicación

Esta aplicación solicita los siguientes permisos, cada uno con un propósito claro:

  • READ_CONTACTS: Se utiliza para seleccionar contactos al crear accesos directos de llamada/SMS. Solo se lee durante acciones iniciadas por el usuario, nunca en segundo plano ni se carga.
  • READ_EXTERNAL_STORAGE: Se utiliza para seleccionar archivos, carpetas e iconos personalizados. Solo se accede cuando el usuario los selecciona activamente.
  • QUERY_ALL_PACKAGES: Se utiliza para listar las aplicaciones instaladas al crear accesos directos de aplicaciones.
  • INSTALL_SHORTCUT: Se utiliza para crear accesos directos en la pantalla de inicio.

Almacenamiento y seguridad de datos

Todos los datos de esta aplicación se almacenan en el almacenamiento local del dispositivo del usuario, incluyendo:

  • La información de configuración de los accesos directos se almacena en las SharedPreferences de la aplicación.
  • Los iconos personalizados se almacenan localmente en el dispositivo.

Esta aplicación no sincroniza ningún dato con la nube ni con servidores remotos. La desinstalación de esta aplicación eliminará automáticamente todos los datos locales.

Los usuarios pueden eliminar todos los datos asociados en cualquier momento desinstalando esta aplicación.

Servicios de terceros

Al crear accesos directos de sitios web, esta aplicación obtiene los iconos de los sitios web a través del siguiente servicio:

  • API de Google Favicon (https://www.google.com/s2/favicons): Solo se envía el dominio del sitio web para obtener el icono correspondiente. No se incluye ninguna información de identidad del usuario.

Aparte del servicio anterior, esta aplicación no integra ningún servicio de análisis, publicidad ni rastreo de terceros.

Cumplimiento del RGPD

En cumplimiento del Reglamento General de Protección de Datos (RGPD) de la Unión Europea, declaramos lo siguiente:

  • Responsable del tratamiento: AnyCut actúa como responsable del tratamiento. Dado que esta aplicación no recopila ningún dato personal, no son necesarias solicitudes de derechos de los interesados.
  • Base legal: Esta aplicación no procesa datos personales, por lo que no se requiere ninguna base legal conforme al artículo 6 del RGPD.
  • Derechos de los interesados: Aunque esta aplicación no recopila datos personales, usted conserva todos los derechos bajo el RGPD, incluidos el derecho de acceso, rectificación, supresión, limitación del tratamiento, portabilidad de los datos y oposición.
  • Notificación de violación de datos: Dado que no se recopilan ni almacenan datos personales, no pueden producirse violaciones de datos que afecten a los datos personales del usuario.
  • Delegado de protección de datos (DPD): Dado que esta aplicación no procesa datos personales, no se ha designado a un Delegado de protección de datos (DPD). Para cualquier consulta relacionada con la privacidad, póngase en contacto con nosotros en support@anycut.app.

Si tiene alguna inquietud respecto al cumplimiento del RGPD, usted tiene derecho a presentar una reclamación ante su Autoridad local de Protección de Datos o ante la autoridad de control del Estado miembro de la UE donde resida.

Privacidad infantil

Esta aplicación no está dirigida a niños menores de 13 años, y no recopilamos deliberadamente información personal de niños. Dado que esta aplicación no recopila ninguna información personal, no existe ninguna amenaza para la privacidad infantil. Si descubre que un niño nos ha proporcionado información, póngase en contacto con nosotros y lo abordaremos de inmediato.

Cambios en la política

Es posible que actualicemos esta política de privacidad de vez en cuando. Las políticas actualizadas se publicarán en esta página con una fecha de «Última actualización» actualizada. Recomendamos a los usuarios que revisen esta página regularmente para conocer la última política de privacidad.

En caso de cambios significativos en la política, notificaremos a los usuarios a través de notificaciones destacadas dentro de la aplicación.
