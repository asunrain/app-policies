はじめに

PixKit（パッケージ名 com.sun.rain.pixkit）は、Android 向けの画像ツールボックスです。日常的に使う画像処理を 1 つのアプリにまとめています。画像の圧縮、形式の変換、画像から PDF への変換、コラージュ、テキスト透かしの追加、サイズ変更、トリミングと回転、そして寸法や EXIF などの画像情報の表示です。

これらの機能はすべてお使いの端末上で完結します。PixKit にはユーザーアカウントも、自社サーバーも、クラウドサービスもなく、あなたの画像がどこかへ送信されることはありません。ネットワークを切った状態でもすべての機能を使えます。接続が必要なのは、第 3 項に記載する任意のリワード動画のみです。

本プライバシーポリシーでは、PixKit のご利用にあたってどのような情報が処理されるのか、その理由、そしてあなたが選べることを説明します。本アプリをインストールしてご利用いただくことで、以下の内容をご承知いただいたものとみなします。

収集する情報

当方は自社サーバー上で個人データを収集・送信・保存することはありません。具体的には次のとおりです。

  • アカウントなし：登録もログインもありません。氏名、メールアドレス、電話番号、パスワードを求めることは一切ありません。
  • 自社の解析なし：当方独自の解析、クラッシュレポート、トラッキング SDK は組み込んでおらず、あなたのプロファイルを作成することもありません。
  • 画像は端末内に留まります：選択した写真は端末のメモリ上でデコード・処理されます。当方や第三者に送信されることはなく、当方は複製を保持しません。
  • 設定は端末内に留まります：外観、言語、保存方法、本日使用した無料回数、ロック解除の状態といった設定は、端末上の本アプリのプライベート領域にのみ保存されます。
  • 書き出したファイルは端末内に留まります：保存した結果は、第 6 項に記載するとおり、あなた自身のストレージに書き込まれます。

例外は 2 つだけで、いずれもお客様の写真とは関係ありません。広告：Google Mobile Ads SDK が一部のデータを自動的に処理します（第 3 節）。購入：Pro を購入した場合、支払いは Google Play が処理し、私たちが受け取るのは購入トークンのみです（第 7 節）。

広告と第三者サービス

PixKit は無料で提供されており、Google AdMob（Google Mobile Ads SDK）による広告で運営を支えています。

使用する広告フォーマットは 1 つだけです。任意のリワード動画で、自動的に表示されることも、作業を中断させることもありません。アプリに用意された 1 日分の無料回数を使い切ったあと、短い動画を視聴して回数を追加するかどうかを選べます。視聴はあくまで任意であり、動画が利用できない場合でもアプリはそのまま使えます。

広告の配信と計測のため、Google Mobile Ads SDK は以下の情報を自動的に収集・共有する場合があります。

  • 端末の広告識別子（Android 広告 ID）およびアプリセット ID（App Set ID）
  • IP アドレス（これにより都市レベル程度の概算位置が導出される場合があります）
  • 端末の種類、OS のバージョン、アプリのバージョン、言語などの技術情報
  • 表示された広告および広告への操作に関する情報

これらの情報は、広告およびマーケティング、広告効果の測定、不正防止のために使用され、Google の広告パートナーと共有される場合があります。通信は暗号化されています。

明確にしておきます。広告 SDK があなたの写真、書き出したファイル、ギャラリーの内容を受け取ることはありません。

広告識別子とパーソナライズ広告は、端末上でいつでも管理できます。

  • Android：設定 → プライバシー → 広告（または Google → 広告）— 広告 ID の削除・リセット、広告のパーソナライズのオプトアウトができます。
  • 法令で求められる地域（欧州経済領域、英国、スイス）では、パーソナライズ広告はあなたの同意を前提とします。広告識別子を使用する前に、アプリ内に表示される同意フォームで同意するか拒否するかをお選びいただけます。選択はいつでも変更できます。

Google によるデータの取り扱いの詳細はこちらをご覧ください。

  • Google プライバシー ポリシー：https://policies.google.com/privacy
  • Google のサービスを使用するサイトやアプリから収集した情報の Google による使用：https://policies.google.com/technologies/partner-sites

Google AdMob 以外に、PixKit が第三者製の解析・広告・トラッキングサービスを組み込むことはありません。

情報の利用目的

当方はあなたの個人データを利用しません。そもそも収集していないためです。広告 SDK が処理する限られた情報は、第 3 項に記載するとおり、リワード動画の表示、広告効果の測定、不正防止のみに使用されます。

当方があなたの個人情報を販売することはありません。また、アプリとその広告の運営に関係のない目的で利用することもありません。

アプリの権限

PixKit は権限をできる限り要求しません。アプリが宣言している権限の全一覧は次のとおりです。

  • android.permission.INTERNET — 任意のリワード動画の読み込みと、Google Play を通じた買い切りの Pro 購入の処理にのみ使用します。ネットワークがなくてもすべてのツールが動作します。
  • com.android.vending.BILLING — 買い切りの Pro 購入を行うために Google Play 請求ライブラリが宣言する権限です。実行時権限ではないためインストール時に確認は表示されず、端末内のいかなるデータにもアクセスできません。
  • android.permission.ACCESS_NETWORK_STATE — 広告を要求する前に接続が利用可能かを確認するため、広告 SDK が使用します。
  • com.google.android.gms.permission.AD_ID — Android 13 以降で必要となる、広告 SDK による広告識別子へのアクセスを許可します。
  • ACCESS_ADSERVICES_AD_ID、ACCESS_ADSERVICES_ATTRIBUTION、ACCESS_ADSERVICES_TOPICS — Android のプライバシーサンドボックス向けに Google Mobile Ads SDK が宣言するもので、広告に関するものであり、あなたの写真とは関係ありません。
  • また PixKit は AndroidX の内部権限（DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION）を 1 つ継承していますが、これはアプリ自身の内部ブロードキャストを保護するだけで、ユーザーデータへのアクセスは伴いません。

PixKit は以下を要求しません。カメラ、マイク、連絡先、カレンダー、正確または概算の位置情報、電話、SMS、身体センサー、そして写真・メディア・ストレージに関するいかなる権限も要求しません。具体的には、READ_MEDIA_IMAGES、READ_MEDIA_VIDEO、READ_EXTERNAL_STORAGE、WRITE_EXTERNAL_STORAGE、MANAGE_EXTERNAL_STORAGE、WAKE_LOCK、FOREGROUND_SERVICE を宣言していません。

写真とファイルの取り扱い

PixKit は画像ツールであるため、この項目は個別に説明する価値があります。

  • 画像がアプリに渡る経路：Android のシステムフォトピッカー（OS 自身の写真ダイアログ）のみです。PixKit がギャラリー全体にアクセスすることはなく、あなたが明示的に選択した個々の画像だけを見ることができます。
  • 処理する場所：お使いの端末のメモリ上、端末内で処理します。アップロードの工程も、待ち行列も、バックグラウンド転送もありません。
  • 結果の保存先：あなた自身のストレージです。画像は Pictures/PixKit、PDF は Downloads/PixKit に保存されるか、システムのファイルダイアログで指定したフォルダに保存されます。ファイルマネージャーやギャラリーアプリでいつでも削除できます。
  • 元の画像は変更しません：どのツールも新しいファイルを書き出します。選択した画像を上書きしたり変更したりすることはありません。
  • クラウドもアカウントもありません：PixKit にサーバー側の構成要素はありません。処理した内容が開発者や第三者に送信されることはありません。
  • 設計上オフラインで動作します：機内モードにしてもすべてのツールが使えます。接続が必要なのは第 3 項に記載した任意のリワード動画のみです。
  • お客様の責任：使用する権利をお持ちの画像のみを処理してください。PixKit は汎用ツールであり、第三者の素材に関する権利を付与するものではありません。

画像情報ツールは、ファイルに既に記録されている情報（カメラの機種、露出設定、位置情報タグなど）を読み取って端末内で表示するだけです。この情報を送信することも、ファイルを変更することもありません。

アプリ内課金と Google Play

PixKit の購入項目は任意の 1 つのみ、PixKit Pro です。内容は 1 日の操作回数制限の解除とリワード動画の停止です。サブスクリプションではなく買い切りで、もともと制限されている機能を解放するものではありません。無料版でもすべてのツールと形式を利用できます。

支払いはすべて Google Play が処理します。私たちがお客様の氏名、カード番号、請求先住所、その他の支払い情報を見たり保存したりすることはありません。Google Play Developer API を通じて確認できるのは購入トークンと商品 ID のみで、用途は 2 つだけです。お使いの端末で Pro を有効にすること、そして返金やサポートの対応です。

権利は Google アカウントに紐づくため、アプリを再インストールした場合や同じアカウントで別の端末にインストールした場合、自動的に復元されます。PixKit は有効状態を端末内のプライベート領域に保存するため、購入後はオフラインでも利用できます。

返金は Google Play のポリシーに従って処理されます。購入に問題があれば、まず android.sun.rain@gmail.com までご連絡ください。私たちが支援します。Google Play から返金を申請することもでき、本ポリシーは消費者としての法的権利に影響しません。

Google による支払い情報の取り扱いについては、Google プライバシー ポリシーをご覧ください：https://policies.google.com/privacy

データの保存と安全

アプリのデータはすべてお使いの端末内のプライベート領域に保存され、サーバー上に複製は存在しません。

ローカルに保存されるデータは、外観と言語の設定、保存方法の設定、本日に使用した無料回数、ロック解除の状態です。

書き出した画像と PDF は第 6 項に記載の場所に書き込まれ、削除するまでそこに残ります。

アプリをアンインストールするとこれらの設定は削除されます。Android の設定 → アプリ → PixKit → ストレージ → ストレージを消去からいつでも消去することもできます。書き出したファイルはアンインストールでは削除されません。ギャラリーやファイルマネージャーから削除してください。

これらのいずれにもストレージ権限は必要ありません。当方が管理するデータについては合理的な技術的措置を講じますが、いかなる保存方法も完全に安全とは言えない点にご留意ください。

GDPR / 英国 GDPR に基づく権利

欧州経済領域、英国、スイスのいずれかに所在する場合、以下が適用されます。

処理の法的根拠（GDPR 第 6 条）：

  • 同意（第 6 条 1(a)）— パーソナライズ広告、および広告識別子など端末上の情報へのアクセス・保存について。ePrivacy 指令第 5 条 3 項に基づくものです。広告識別子を使用する前に、Google 認定の同意管理プラットフォームが提供する同意フォームを表示します。同意するか拒否するかを選べ、いつでも同意を撤回できます。
  • 正当な利益（第 6 条 1(f)）— 非パーソナライズ広告の配信、アプリの機能と安全の維持、不正や濫用の防止のため。

あなたの権利：個人データへのアクセス、訂正、削除、処理の制限を求める権利、データポータビリティの権利、処理に異議を述べる権利、いつでも同意を撤回する権利があります。撤回は、撤回前に行われた処理の適法性に影響しません。また、自動化された処理のみに基づく決定に服さない権利があります。

権利の行使方法：android.sun.rain@gmail.com までご連絡ください。お住まいのデータ保護監督機関に苦情を申し立てる権利もあります。

データ管理者：PixKit の開発者（上記メールアドレス）。当方は、選任が必要となる処理を行っていないため、データ保護責任者を選任していません。

PixKit 自体は個人データを収集しないため、広告データに関するご請求は広告 SDK の提供元である Google にお申し出いただくのが最も適切です。当方も可能な限り協力いたします。

カリフォルニア州のプライバシー権

カリフォルニア州の居住者である場合、CCPA/CPRA により個人情報に関する特定の権利が認められます。

  • 過去 12 か月間において、広告 SDK は第 3 項に記載するとおり、クロスコンテキスト行動ターゲティング広告のために広告 ID などの識別子を広告パートナーと「共有」した可能性があります。当方は金銭的価値のために個人情報を販売することはありません。
  • ターゲティング広告のための個人情報の共有を拒否する権利があります。最も簡単な方法は、端末の設定で広告のパーソナライズを無効にするか広告 ID を削除する（第 3 項）、あるいは同意フォームが表示されたときに拒否することです。
  • また、個人情報について知る権利、削除する権利、訂正する権利、およびこれらの権利を行使したことを理由に差別されない権利があります。

請求を行うには android.sun.rain@gmail.com までご連絡ください。当方は 16 歳未満の消費者の個人情報を故意に販売または共有しません。

子どものプライバシー

PixKit は汎用のユーティリティアプリであり、13 歳未満（現地法が求める場合は 16 歳未満）の子どもを対象としていません。子どもから個人情報を故意に収集することはありません。本アプリにはユーザーアカウント、チャット、メッセージ、ソーシャル機能、ユーザー生成コンテンツはありません。

保護者の方は、第 3 項に記載の方法で端末上の広告のパーソナライズを無効にすることもできます。

子どもが当方に個人情報を提供したと思われる場合は、ご連絡いただければ削除いたします。

データの保持

当方のサーバーに個人データを保持することはありません。端末内に保存されたデータは、アプリのストレージを消去するかアンインストールするまで残ります。書き出したファイルは、あなたが削除するまでご自身のストレージに残ります。Google Mobile Ads SDK が処理するデータは、Google 自身の保持ポリシーに従って保持されます。

国際的なデータ移転

広告データは、Google およびそのパートナーにより、お住まいの国以外の国（米国を含む）に移転され処理される場合があります。必要な場合、こうした移転は欧州委員会の標準契約条項や EU-米国データプライバシーフレームワーク（英国への拡張を含む）といった適切な保護措置に基づいて行われます。

PixKit 自体は、個人データを一切送信しないため、何も移転しません。

本プライバシーポリシーは随時更新することがあります。更新版は本ページに掲載し、上部の「最終更新日」を新しくします。重要な変更については、アプリ内またはストアの掲載情報でお知らせします。

更新後もアプリの利用を続けた場合、改訂後のポリシーに同意したものとみなされます。
