Introduzione

FileVerifier (di seguito "questa app") è uno strumento di verifica dell'integrità dei file per Android che consente agli utenti di calcolare valori hash (MD5, SHA-1, SHA-256, SHA-384, SHA-512, CRC32, Adler-32) per i file, verificare i file rispetto ai valori hash attesi ed eseguire un confronto binario byte per byte tra due file per identificare le differenze.

Prendiamo seriamente la vostra privacy. Questa informativa sulla privacy spiega le nostre pratiche relative alla raccolta, all'uso e alla protezione delle informazioni. Utilizzando questa app, accettate i termini descritti nella presente informativa sulla privacy.

Informazioni che raccogliamo

Questa app non raccoglie, carica o memorizza alcuna informazione personale identificabile. Nello specifico:

  • Non richiede registrazione o accesso; non raccoglie nomi utente, email, password o altre informazioni dell'account.
  • Non raccoglie identificatori del dispositivo (come IMEI, Android ID), informazioni sulla posizione o altri dati del dispositivo.
  • Non utilizza strumenti di analisi web (come Google Analytics) per tracciare il comportamento degli utenti.
  • Non contiene SDK pubblicitari.
  • Non richiede il permesso Internet e funziona completamente offline.

I file vengono selezionati da voi tramite il selettore di file del sistema e vengono elaborati solo nella memoria del dispositivo durante il calcolo dell'hash o il confronto. I contenuti dei file non vengono mai letti, caricati o memorizzati da questa app.

Uso delle informazioni

Poiché questa app non raccoglie informazioni personali, non esiste un ulteriore utilizzo delle informazioni personali. Questa app elabora solo localmente in memoria i seguenti dati:

  • Percorsi dei file e metadati: Quando selezionate un file, questa app legge il nome e la dimensione del file per visualizzarli sullo schermo. Queste informazioni non vengono memorizzate né caricate.
  • Contenuti dei file: Durante il calcolo dei valori hash o il confronto di due file, i contenuti vengono letti in memoria in modalità streaming per il calcolo. I contenuti non vengono mai salvati o trasmessi.
  • Risultati hash: I valori hash calcolati vengono visualizzati solo sullo schermo. La copia negli appunti viene eseguita interamente dal sistema del vostro dispositivo e non viene monitorata da questa app.

Autorizzazioni dell'app

Questa app non richiede alcuna autorizzazione di runtime. Tutto l'accesso ai file avviene tramite il selettore di file del sistema Android (Storage Access Framework), in cui voi selezionate attivamente i file da elaborare.

  • Nessuna autorizzazione di archiviazione richiesta: il selettore di file del sistema gestisce l'accesso al posto vostro.
  • Nessuna autorizzazione di rete richiesta: questa app funziona completamente offline.

Archiviazione e sicurezza dei dati

Questa app non memorizza alcun dato sul vostro dispositivo:

  • Non viene creato alcun database locale o cache di file.
  • Nessuna cronologia, impostazione o statistica viene conservata.
  • Nessun dato viene sincronizzato con il cloud o con server remoti.

Tutti i calcoli vengono eseguiti in memoria e i risultati vengono scartati quando termina il processo dell'app. La disinstallazione di questa app rimuove tutte le tracce dell'applicazione dal vostro dispositivo.

Servizi di terze parti

Questa app non integra alcun servizio di terze parti, inclusi, a titolo esemplificativo, SDK di analisi, pubblicità, segnalazione di crash o tracciamento. Non esiste alcuna comunicazione di rete di alcun tipo.

Conformità al GDPR

In conformità con il Regolamento Generale sulla Protezione dei Dati (GDPR) dell'Unione Europea, dichiariamo quanto segue:

  • Titolare del trattamento: FileVerifier agisce come titolare del trattamento. Poiché questa app non raccoglie dati personali, non sono necessarie richieste relative ai diritti degli interessati.
  • Base giuridica: Questa app non tratta dati personali, pertanto non è richiesta alcuna base giuridica ai sensi dell'articolo 6 del GDPR.
  • Diritti degli interessati: Sebbene questa app non raccolga dati personali, conservate tutti i diritti previsti dal GDPR, inclusi il diritto di accesso, rettifica, cancellazione, limitazione del trattamento, portabilità e opposizione.
  • Notifica di violazione dei dati: Poiché non vengono raccolti o memorizzati dati personali, non possono verificarsi violazioni dei dati che interessino i dati personali degli utenti.
  • Responsabile della protezione dei dati: Poiché questa app non tratta dati personali, non è stato nominato un responsabile della protezione dei dati (DPO). Per qualsiasi domanda relativa alla privacy, contattateci all'indirizzo android.sun.rain@gmail.com.

Se avete dubbi sulla conformità al GDPR, avete il diritto di presentare un reclamo alla vostra autorità locale per la protezione dei dati o all'autorità di controllo dello Stato membro dell'UE in cui risiedete.

Privacy dei minori

Questa app non è rivolta a minori di 13 anni e non raccogliamo consapevolmente informazioni personali da minori. Poiché questa app non raccoglie informazioni personali, non esiste alcuna minaccia alla privacy dei minori. Se scoprite che un minore ci ha fornito informazioni, contattateci e provvederemo tempestivamente.
