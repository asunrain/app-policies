Introduction

FileVerifier (hereinafter "this app") is an Android file integrity verification tool that allows users to calculate hash values (MD5, SHA-1, SHA-256, SHA-384, SHA-512, CRC32, Adler-32) for files, verify files against expected hash values, and perform byte-by-byte binary comparison between two files to identify differences.

We take your privacy seriously. This privacy policy explains our practices regarding information collection, use, and protection. By using this app, you agree to the terms described in this privacy policy.

Information We Collect

This app does not collect, upload, or store any personally identifiable information. Specifically:

  • This app does not require registration or login and does not collect usernames, emails, passwords, or other account information.
  • This app does not collect device identifiers (such as IMEI, Android ID), location information, or other device data.
  • This app does not use any web analytics tools (such as Google Analytics) to track user behavior.
  • This app does not contain any advertising SDKs.
  • This app does not request the Internet permission and is fully offline.

Files are selected by you through the system file picker and are processed only in the device's memory during hash calculation or comparison. File contents are never read, uploaded, or stored by this app.

How We Use Information

Since this app does not collect any personal information, there is no further use of personal information. This app only processes the following data locally in memory:

  • File paths and metadata: When you select a file, this app reads the file name and size to display them on screen. This information is not stored or uploaded.
  • File contents: When calculating hash values or comparing two files, this app reads file contents into memory in a streaming manner for computation. Contents are never persisted or transmitted.
  • Hash results: Computed hash values are displayed on screen. Copying them to the clipboard is performed entirely by your device's system and is not monitored by this app.

App Permissions

This app requests no runtime permissions. All file access is performed through the Android system file picker (Storage Access Framework), where you actively select files to process.

  • No storage permission is required — the system file picker handles access on your behalf.
  • No Internet permission is required — this app is fully offline.

Data Storage and Security

This app does not store any data on your device:

  • No local database or file cache is created.
  • No history, settings, or statistics are persisted.
  • No data is synced to the cloud or any remote server.

All computations are performed in memory and results are discarded when the app process ends. Uninstalling this app removes all traces of the application from your device.

Third-Party Services

This app does not integrate any third-party services, including but not limited to analytics, advertising, crash reporting, or tracking SDKs. There is no network communication of any kind.
