소개

FileVerifier(이하 "본 앱")는 Android 파일 무결성 검증 도구로, 파일의 해시 값(MD5, SHA-1, SHA-256, SHA-384, SHA-512, CRC32, Adler-32) 계산, 기대 해시 값과의 대조 검증, 두 파일 간 바이트 단위 이진 비교를 통한 차이 식별 기능을 제공합니다.

저희는 귀하의 프라이버시를 중요하게 생각합니다. 본 개인정보 처리방침은 정보 수집, 이용, 보호에 관한 저희의 관행을 설명합니다. 본 앱을 사용하면 본 개인정보 처리방침에 명시된 내용에 동의하는 것으로 간주됩니다.

수집하는 정보

본 앱은 개인을 식별할 수 있는 정보를수집, 업로드, 저장하지 않습니다. 구체적으로:

  • 회원가입이나 로그인이 필요 없으며, 사용자 이름, 이메일, 비밀번호 등 계정 정보를 수집하지 않습니다.
  • 기기 식별자(IMEI, Android ID 등), 위치 정보 또는 기타 기기 데이터를 수집하지 않습니다.
  • Google Analytics 등 웹 분석 도구를 사용하여 사용자 행동을 추적하지 않습니다.
  • 광고 SDK를 포함하지 않습니다.
  • 인터넷(INTERNET) 권한을 요청하지 않으며 완전히 오프라인으로 작동합니다.

파일은 귀하가 시스템 파일 선택기를 통해 직접 선택하며, 해시 계산 또는 비교 중에만 기기 메모리에서 처리됩니다. 파일 내용은절대 읽히거나 업로드되거나 저장되지 않습니다.

정보의 이용 방법

본 앱은 개인정보를 수집하지 않으므로 개인정보의 추가 이용이 없습니다. 본 앱은 기기 메모리에서 로컬로 다음 데이터만 처리합니다:

  • 파일 경로 및 메타데이터: 파일을 선택하면 화면 표시를 위해 파일 이름과 크기를 읽습니다. 이 정보는 저장되거나 업로드되지 않습니다.
  • 파일 내용: 해시 값을 계산하거나 두 파일을 비교할 때 파일 내용을 스트리밍 방식으로 메모리에 읽어 계산합니다. 내용은 절대 저장되거나 전송되지 않습니다.
  • 해시 결과: 계산된 해시 값은 화면에 표시될 뿐입니다. 클립보드로의 복사는 귀하의 기기 시스템이 수행하며 본 앱은 이를 감시하지 않습니다.

앱 권한

본 앱은런타임 권한을 일절 요청하지 않습니다. 모든 파일 접근은 Android 시스템 파일 선택기(Storage Access Framework)를 통해 이루어지며, 처리할 파일을 귀하가 직접 선택합니다.

  • 저장소 권한 불필요 — 시스템 파일 선택기가 대신 접근을 처리합니다.
  • 네트워크 권한 불필요 — 본 앱은 완전히 오프라인으로 작동합니다.

데이터 저장 및 보안

본 앱은 귀하의 기기에어떤 데이터도 저장하지 않습니다:

  • 로컬 데이터베이스나 파일 캐시를 생성하지 않습니다.
  • 기록, 설정 또는 통계 데이터를 영구 저장하지 않습니다.
  • 클라우드나 원격 서버로 데이터를 동기화하지 않습니다.

모든 계산은 메모리에서 이루어지며 앱 프로세스가 종료되면 결과는 폐기됩니다. 본 앱을 제거하면 기기에서 앱의 모든 흔적이 삭제됩니다.

제3자 서비스

본 앱은어떤 제3자 서비스도 통합하지 않습니다. 분석, 광고, 크래시 리포트, 추적 SDK를 포함하되 이에 국한되지 않습니다. 어떤 형태의 네트워크 통신도 없습니다.

GDPR 준수

유럽연합의 일반 데이터 보호 규정(GDPR)을 준수하기 위해 다음과 같이 선언합니다:

  • 데이터 컨트롤러: FileVerifier가 데이터 컨트롤러 역할을 합니다. 본 앱은 개인 데이터를 수집하지 않으므로 데이터 주체 권리 요청 처리가 필요 없습니다.
  • 법적 근거: 본 앱은 개인 데이터를 처리하지 않으므로 GDPR 제6조에 따른 법적 근거가 필요하지 않습니다.
  • 데이터 주체 권리: 본 앱은 개인 데이터를 수집하지 않지만, 접근권, 정정권, 삭제권, 처리 제한권, 데이터 이동권, 반대권 등 GDPR이 부여한 모든 권리를 보유합니다.
  • 데이터 유출 통지: 개인 데이터를 수집하거나 저장하지 않으므로 사용자 개인 데이터에 영향을 미치는 유출은 발생할 수 없습니다.
  • 데이터 보호 책임자: 본 앱은 개인 데이터를 처리하지 않으므로 데이터 보호 책임자(DPO)를 임명하지 않았습니다. 개인정보 관련 문의는 android.sun.rain@gmail.com으로 연락해 주시기 바랍니다.

GDPR 준수에 대해 우려 사항이 있으시면 거주 지역 또는 거주 중인 EU 회원국의 감독 기관에 불만을 제기할 권리가 있습니다.
