소개

충전 탐정(이하 "본 앱")은 Android 배터리 충전 모니터링 도구로, 충전 과정의 전압, 전류, 온도, 배터리 잔량, 전력을 실시간으로 기록하고 충전 곡선과 건강 보고서를 통해 충전기의 상태를 분석합니다.

당사는 귀하의 개인정보를 소중히 여깁니다. 본 개인정보 처리방침은 정보 수집, 이용, 보호에 관한 당사의 방침을 설명합니다. 본 앱을 사용함으로써 귀하는 본 방침에 명시된 약관에 동의하게 됩니다.

수집하는 정보

본 앱은 개인을 식별할 수 있는 정보를 수집, 업로드 또는 저장하지 않습니다. 구체적으로:

  • 본 앱은 회원가입이나 로그인이 필요하지 않으며, 사용자 이름, 이메일, 비밀번호 등 계정 정보를 수집하지 않습니다.
  • 본 앱은 기기 식별자(IMEI, Android ID 등), 위치 정보 또는 기타 기기 데이터를 수집하지 않습니다.
  • 본 앱은 사용자 행동을 추적하기 위한 웹 분석 도구(Google Analytics 등)를 사용하지 않습니다.
  • 본 앱은 광고 SDK를 포함하지 않습니다.
  • 본 앱은 네트워크 권한을 보유하지 않아 인터넷에 접속하거나 데이터를 전송할 수 없습니다.

본 앱이 기록하는 모든 충전 세션 데이터(전압, 전류, 온도, 잔량, 전력 및 관련 이벤트)는 기기 로컬에만 저장되며 어떠한 서버로도 전송되지 않습니다.

정보의 이용 방법

본 앱은 개인정보를 수집하지 않으므로 개인정보의 추가 이용이 없습니다. 본 앱은 다음 데이터를 기기 내에서만 처리합니다:

  • 충전 텔레메트리 데이터: 모니터링 세션을 시작하면 본 앱은 약 1초 간격으로 배터리 전압, 전류, 온도, 잔량을 샘플링합니다. 이 데이터는 기기에서 실시간 통계 표시와 충전 곡선·건강 보고서 생성에만 사용됩니다.
  • 충전 프로토콜 인식: 본 앱은 측정된 전압과 전류로 충전 프로토콜(USB DCP, QC, PD 등)을 추정합니다. 추정 결과는 귀하에게 표시되고 로컬에 저장될 뿐, 외부로 전송되지 않습니다.
  • 앱 설정: 표시 언어, Pro 상태 등 귀하의 설정은 기기 로컬에만 저장됩니다.
  • 공유 기능: 공유 버튼을 명시적으로 탭한 경우에만 CSV, 이미지 또는 텍스트 보고서가 시스템 공유 시트로 내보내지며, 전송 대상을 직접 선택합니다. 공유는 항상 사용자가 직접 시작합니다.

앱 권한

본 앱은 각각 명확한 목적을 가진 다음 권한을 요청합니다:

  • 포그라운드 서비스(FOREGROUND_SERVICE + FOREGROUND_SERVICE_SPECIAL_USE): 모니터링 세션 중 포그라운드 서비스를 유지하여 충전 텔레메트리 데이터를 지속적으로 샘플링하는 데 사용합니다(이러한 모니터링 기능에 대한 Android 14 이상의 요구 사항).
  • 알림(POST_NOTIFICATIONS): 모니터링 세션 실행 중 충전 상태 알림을 표시하는 데 사용합니다.

본 앱은 다른 권한을 요청하지 않으며, 연락처, 위치, 파일, 카메라, 마이크에 접근하지 않습니다.

데이터 저장 및 보안

본 앱의 모든 데이터는 사용자 기기의 로컬 저장소에 저장됩니다:

  • 충전 세션 기록은 앱의 비공개 저장소 내 로컬 데이터베이스(Room)에 저장됩니다.
  • 앱 설정은 SharedPreferences에 저장됩니다.
  • 내보낸 CSV, 이미지 및 보고서 텍스트는 앱의 캐시 디렉터리에 기록되며, 공유를 선택한 경우에만 존재합니다.

본 앱은 클라우드나 원격 서버에 데이터를 동기화하지 않습니다. 본 앱을 제거하면 모든 로컬 데이터가 자동으로 삭제됩니다.

사용자는 언제든지 앱을 제거하여 관련 데이터를 모두 삭제할 수 있습니다.

제3자 서비스

본 앱은 제3자 분석, 광고, 추적 또는 데이터 수집 서비스를 통합하지 않으며, 제3자 서버에도 연결하지 않습니다.

GDPR 준수

유럽연합의 일반 데이터 보호 규정(GDPR)을 준수하여 다음과 같이 선언합니다:

  • 데이터 관리자: 충전 탐정이 데이터 관리자입니다. 본 앱은 개인 데이터를 수집하지 않으므로 데이터 주체 권리 요청 처리가 필요하지 않습니다.
  • 법적 근거: 본 앱은 개인 데이터를 처리하지 않으므로 GDPR 제6조에 따른 법적 근거가 필요하지 않습니다.
  • 데이터 주체 권리: 본 앱이 개인 데이터를 수집하지 않더라도 접근, 정정, 삭제, 처리 제한, 데이터 이동, 반대 권리를 포함한 GDPR상의 모든 권리를 보유합니다.
  • 데이터 유출 통지: 개인 데이터를 수집하거나 저장하지 않으므로 사용자 개인 데이터에 영향을 미치는 데이터 유출이 발생할 수 없습니다.
  • 데이터 보호 책임자: 본 앱은 개인 데이터를 처리하지 않으므로 데이터 보호 책임자(DPO)를 지정하지 않았습니다. 개인정보 관련 문의는 android.sun.rain@gmail.com으로 연락해 주십시오.

GDPR 준수에 관해 우려가 있는 경우, 거주 지역의 데이터 보호 당국 또는 거주하는 EU 회원국의 감독 기관에 이의를 제기할 권리가 있습니다.
